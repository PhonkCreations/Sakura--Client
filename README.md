# 🌸 Sakura Client

A Minecraft Fabric client for **1.21.4** with a custom pink GUI, falling petals, HUD, subcategories and config persistence.

## ✨ Features

- 🎮 **Minecraft:** 1.21.4
- 🔧 **Loader:** Fabric
- ☕ **Java:** 21
- 🎨 **Theme:** Sakura (pink + dark)
- 📦 **Modules:** 30+ in development
- 💾 **Config persistence**
- 🌸 **Custom GUI** with falling petals + subcategories

## 📥 Installation

1. Install **Fabric Loader** for Minecraft 1.21.4
2. Download **Fabric API** 0.119.4+1.21.4
3. Download the Sakura Client jar from [Releases](https://github.com/PhonkCreations/Sakura-Client/releases)
4. Drop both jars into `%appdata%\.minecraft\mods\`
5. Launch Minecraft with the `fabric-loader-1.21.4` profile
6. Press **Right Shift** in-game to open the GUI

## 🎮 Controls

- **Right Shift** — Open/close GUI
- **Left click** on module — Toggle on/off
- **Left click + drag on header** — Move panel
- **X button** — Close GUI
